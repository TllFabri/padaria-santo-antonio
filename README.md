# Padaria Santo Antônio — Site Institucional

Site institucional da **Padaria Santo Antônio**, em Goianá (MG) — mais de 100 anos de tradição e o maior forno a lenha do Brasil.

> 💼 **Projeto freelancer**: desenvolvido sob demanda e vendido para a padaria, do levantamento das necessidades do cliente até o site publicado e pronto para uso.

## Funcionalidades

- Layout responsivo (celular, tablet e desktop) com menu mobile
- Seções de história, produtos, galeria, encomendas e localização
- Galeria de fotos com lightbox
- Encomendas direto pelo WhatsApp (incluindo o frango assado de domingo)
- Mapa do Google incorporado com a localização da padaria
- Animações ao rolar a página

## Tecnologias

- HTML, CSS e JavaScript puro (sem frameworks)
- Deploy na [Vercel](https://vercel.com)

## Estrutura

```
site/
├── index.html      # conteúdo do site
├── css/style.css   # estilos
├── js/script.js    # menu, animações e galeria
└── img/            # logo e fotos dos produtos
```

## Rodando localmente

Basta abrir `site/index.html` no navegador, ou usar a extensão Live Server do VS Code.
